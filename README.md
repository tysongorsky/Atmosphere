# Neighbourhood Glow

Neighbourhood Glow is a complete Progressive Web App and lighting-control server for community lighting experiences.

## Installation

```bash
npm install
```

## Start the app

```bash
npm start
```

## Development mode

```bash
npm run dev
```

## Access

- Audience page: http://localhost:3000/
- Admin page: http://localhost:3000/admin.html

This project is configured for the Node.js runtime and uses the standard npm scripts defined in `package.json`.
